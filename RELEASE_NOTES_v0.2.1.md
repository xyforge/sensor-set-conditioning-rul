# v0.2.1 — code-only release

This release packages the analysis code, frozen protocol contracts, decision
snapshots, compact calibration and C-MAPSS results, and reproducibility
metadata for *Sensor-Set Conditioning for Prognostic Posterior Consistency*.

The manuscript source, figures, tables, bibliography, and compiled PDF are
intentionally withheld from this release while the paper is being prepared for
submission. They remain available only in the historical private `v0.2.0` tag
and can be restored in a later release.

Raw C-MAPSS files, large prediction stores, local GPU checkpoints, and private
server information remain excluded.
