# TSFM-PHM LaTeX manuscript

This directory is a standalone manuscript structure generated from the
track-by-track enhancement outputs.

## Build

From this directory:

```bash
pdflatex main.tex
bibtex main
pdflatex main.tex
pdflatex main.tex
```

The canonical manuscript uses the active narrative chapters in
`sections/01_abstract.tex` through `sections/06_conclusion_honest.tex`, with
the Methods chapter in `sections/03_methods.tex`. The build uses `tables/` for
publication tables and `figures/` for the manuscript figures.

The compiled manuscript is written to `main.pdf`.

## Figures

The manuscript now includes seven figures in `figures/`:

- `fig1_prop_direct_architecture.png`: PROP-DIRECT conditioning versus masking.
- `fig2_c1_main_result_forest.png`: C1 test/lockbox forest plot.
- `fig3_c2_pair_class_decomposition.png`: C2 pair-class decomposition.
- `fig4_synthetic_generator.png`: synthetic degradation generator schematic.
- `fig5_preregistration_protocol.png`: preregistered evaluation protocol.
- `fig6_prediction_example.png`: prediction example across sensor sets.
- `fig7_calibration_reliability.png`: central-coverage and PIT diagnostics on
  the C1 test and lockbox splits.

The quantitative values shown in the C1 and C2 figures match the reported
results and confidence intervals in the manuscript.

The calibration diagnostic is generated by
`../scripts/analysis/calibration_analysis.py` in the full research workspace
and is descriptive; it does not alter preregistered decision rules. The public
release includes the compact outputs and figure, while omitting the large
prediction stores used as input.
