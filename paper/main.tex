\section*{Data Availability Statement}

The public code and manuscript repository is available at
\url{https://github.com/xyforge/sensor-set-conditioning-rul}. It contains the
manuscript source, synthetic-generator specifications and seed settings,
evaluation scripts, shared-model C-MAPSS configurations and results, calibration
summaries, compact score artifacts, and the frozen protocol documents. All
evaluation code and decision rules were frozen before lockbox validation.

Raw C-MAPSS data, large prediction stores, and model checkpoints are excluded
from the repository and can be obtained or regenerated under their respective
access conditions. A persistent DOI can be added when a versioned release is
deposited in a research repository.

\section*{Acknowledgements}

This research was conducted under a preregistered protocol with independent test and lockbox evaluation splits. C-MAPSS turbofan data were provided by NASA Ames Prognostics Center of Excellence. Computational resources were provided by Shanghai University of Engineering Science. All experimental decisions were made prior to accessing validation outcomes to ensure statistical integrity.
