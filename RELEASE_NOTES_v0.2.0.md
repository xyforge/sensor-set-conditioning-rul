# v0.2.0 — timestamped archive candidate

This release packages the manuscript and the frozen reproducibility record for
*Sensor-Set Conditioning for Prognostic Posterior Consistency*.

It adds the current manuscript with the oracle-relative geometry analysis, the
updated nearest-neighbour literature review, the keyword block, and the compact
analysis scripts. It also archives the formal protocol, claim-metric registry,
oracle thresholds, C1/C2 machine-readable contracts, and the final decision
snapshots. The C2 core failure is retained as part of the record.

The archive excludes raw C-MAPSS files, large prediction stores, local GPU
checkpoints, and private server information. C-MAPSS FD001 is a public simulated
benchmark and is not presented as field validation.

The intended next step is to publish this GitHub release through Zenodo so that a
DOI can be assigned. No DOI is claimed until Zenodo publication is complete.
